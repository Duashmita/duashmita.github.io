# Ashmita Dua — Portfolio

Personal portfolio site, live at [duashmita.github.io](https://duashmita.github.io).

## Tech stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build      # outputs to dist/
```

## Deploy

Pushing to `main` triggers the GitHub Pages workflow
(`.github/workflows/deploy.yml`), which builds and publishes `dist/`.
